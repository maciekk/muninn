Muninn Firefox bridge

Start uv run muninn browser-bridge, then paste its pairing token.

Once connected, run muninn check. The worker opens configured Newegg, Best Buy Canada, and Memory Express URLs in a dedicated tab. Complete any verification there. Other tabs are untouched; collection continues when this popup closes.

Or import the current tab manually

Check the product, variant, seller, and currency before importing. Page HTML is saved privately in your local Muninn cache.
