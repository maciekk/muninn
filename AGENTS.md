# Project instructions

- Do not run bare `pytest`; it is not available on the system PATH.
- Run the test suite through uv: `uv run pytest`.
- Read [project notes](docs/project-notes.md) for provisional findings and decision
  context. Record non-obvious lessons that could save repeated investigation;
  include evidence and caveats, and exclude private track/session data. Promote
  stable guidance into the relevant documentation rather than duplicating it.
